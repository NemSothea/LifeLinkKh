## 3. Developer communities · សហគមន៍អ្នកអភិវឌ្ឍ

English first. The aim is contributors, not installs.

### English

> **LifeLink KH: open-source blood-donor matching for Cambodia (Apache-2.0)**
>
> Blood emergencies in Phnom Penh still run on Facebook posts. LifeLink KH matches an urgent request to nearby eligible donors by ABO/Rh and distance, and pushes them an alert.
>
> **Stack:** Flutter (Android APK on GitHub Releases), Next.js 16 portal on Vercel, Firestore with emulator-tested Security Rules, Firebase Auth and FCM. It runs at $0 on free tiers. Everything runs locally on the Firebase emulators, with no team credentials needed.
>
> Khmer-first, bilingual km/en. We especially want native Khmer reviewers.
>
> 🧑‍💻 Repo: https://github.com/NemSothea/LifeLinkKh
> 🌱 Good first issues: https://github.com/NemSothea/LifeLinkKh/issues?q=is%3Aopen+label%3A%22good+first+issue%22
> 📖 Handbook: https://nemsothea.github.io/LifeLinkKh/
