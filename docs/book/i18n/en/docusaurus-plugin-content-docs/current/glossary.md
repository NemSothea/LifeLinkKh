# Glossary: Khmer ↔ English

The words the app itself uses. Translators: keep to these so the app, the website and this book
say the same thing.

| ខ្មែរ | English | Meaning in LifeLink |
|---|---|---|
| ការបរិច្ចាគឈាម | blood donation | One visit to give blood, confirmed by an admin |
| អ្នកបរិច្ចាគឈាម / អ្នកបរិច្ចាគ | blood donor / donor | A user with a donor profile |
| ក្រុមឈាម | blood type / blood group | A+, A-, B+, B-, AB+, AB-, O+, O-: always written in Latin letters |
| ក្រុមឈាមត្រូវគ្នា | compatible blood type | Can be given to the patient, not only the same type |
| ឯកតា | unit | One donated bag; 350 ml in Cambodia |
| ការស្នើសុំ / សំណើ | request | A family's need for blood at one hospital |
| ស្នើសុំឈាម | request blood | The button that starts a request |
| បន្ទាន់បំផុត · បន្ទាន់ · ធម្មតា | critical · urgent · routine | Urgency of a request |
| កំពុងរង់ចាំការពិនិត្យ | waiting for review | Request sent, not yet checked by an admin |
| បើកចំហ | open | Approved; donors are being alerted |
| បានបំពេញ | fulfilled | Enough blood was given |
| បានបោះបង់ | cancelled | Withdrawn by the requester |
| មិនត្រូវបានអនុម័ត | not approved | Rejected by an admin, with a reason |
| យល់ព្រម · បដិសេធ | accept · decline | A donor's answer to an alert |
| អ្នកគ្រប់គ្រង | admin | Reviews requests and confirms donations on the portal |
| អាចទទួលសំណើបាន | available for requests | The switch that pauses alerts |
| ខណ្ឌ | district (khan) | The only location other people see |
| មជ្ឈមណ្ឌលជាតិផ្តល់ឈាម | National Blood Transfusion Center (NBTC) | Phnom Penh's national blood centre |
| ផ្នែកផ្តល់ឈាម | blood bank | The hospital's blood unit |
| ផ្ទាំង «ដើម» · «ប្រវត្តិ» · «ខ្ញុំ» | Home · History · Me tabs | The app's three tabs |
| លុបគណនី | delete account | Removes personal data; anonymous counts stay |
