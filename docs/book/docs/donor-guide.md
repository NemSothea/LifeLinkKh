## ២. ក្លាយជាអ្នកបរិច្ចាគ (៣ ជំហាន)

នៅផ្ទាំង **ដើម** ចុច **បំពេញប្រវត្តិរូបអ្នកបរិច្ចាគរបស់អ្នក**។

| ជំហាន | អ្វីដែលត្រូវបំពេញ | គួរដឹង |
|---|---|---|
| **ឈ្មោះ និងក្រុមឈាមរបស់អ្នក** | ឈ្មោះពេញ ក្រុមឈាម | មិនដឹងក្រុមឈាមរបស់អ្នក? មន្ទីរពេទ្យអាចធ្វើតេស្តបាន។ បើគ្មានវា យើងមិនអាចផ្គូផ្គងអ្នកជាមួយអ្នកជំងឺបានទេ។ |
| **អ្នកនៅទីណា?** | ខណ្ឌរបស់អ្នក។ អាចចុច **ប្រើទីតាំងបច្ចុប្បន្នរបស់ខ្ញុំ** បើចង់ | អ្នកដទៃឃើញតែខណ្ឌរបស់អ្នក — មិនឃើញទីតាំងជាក់លាក់ទេ។ បើគ្មានទីតាំង អ្នកនៅតែត្រូវបានផ្គូផ្គង។ |
| **ការបរិច្ចាគចុងក្រោយ** | ថ្ងៃបរិច្ចាគចុងក្រោយ ឬ **ខ្ញុំមិនដែលបរិច្ចាគទេ** និងភេទ (មិនបង្ខំ) | ប្រើសម្រាប់តែរាប់ថ្ងៃរង់ចាំប៉ុណ្ណោះ។ បើជ្រើស «មិនចង់ប្រាប់» កម្មវិធីនឹងរាប់រយៈពេលវែងជាង។ |

ពេលរក្សាទុករួច កម្មវិធីបង្ហាញ **អ្នកអាចបរិច្ចាគបានឥឡូវនេះ** ឬ **អាចបរិច្ចាគក្នុងរយៈពេល N ថ្ងៃ** ជាមួយកាលបរិច្ឆេទ។

## ៣. រយៈពេលរង់ចាំរវាងការបរិច្ចាគ

LifeLink រាប់ **៣ ខែ (៩០ ថ្ងៃ) សម្រាប់បុរស** និង **៤ ខែ (១២០ ថ្ងៃ) សម្រាប់ស្ត្រី** គិតពីថ្ងៃបរិច្ចាគចុងក្រោយ
ដូចមជ្ឈមណ្ឌលផ្តល់ឈាមនៅកម្ពុជាអនុវត្ត។ បើអ្នកមិនប្រាប់ភេទ កម្មវិធីរាប់ ១២០ ថ្ងៃ។ បុគ្គលិកមជ្ឈមណ្ឌលជាអ្នកសម្រេចចុងក្រោយ។

## ៤. ពេលមានសំណើមកដល់

អ្នកនឹងទទួលបានសារជូនដំណឹង៖ **«សំណើឈាមបន្ទាន់នៅជិតអ្នក — ឈាមរបស់អ្នកត្រូវគ្នា។»** អ្នកក៏អាចរកឃើញវានៅរូបកណ្ដឹង និងក្នុង **សារជូនដំណឹងអ្នកបរិច្ចាគ**។

អ្នកទទួលបានការជូនដំណឹង លុះត្រាតែ **គ្រប់** លក្ខខណ្ឌទាំងនេះពិត៖

- ក្រុមឈាមរបស់អ្នកអាចផ្តល់ឲ្យអ្នកជំងឺបាន (មិនមែនតែក្រុមដូចគ្នាទេ ក្រុមដែលត្រូវគ្នាក៏រាប់ដែរ)
- អ្នក **អាចទទួលសំណើបាន** (មើលខាងក្រោម) និង **អាចបរិច្ចាគបាន** (ផុតរយៈពេលរង់ចាំហើយ)
- អ្នកនៅក្នុងចម្ងាយប្រហែល ១០ គីឡូម៉ែត្រពីមន្ទីរពេទ្យ ឬអ្នកបានផ្តល់តែខណ្ឌប៉ុណ្ណោះ
- អ្នកគ្រប់គ្រងបានពិនិត្យសំណើរួចហើយ (វាបង្ហាញ **អ្នកគ្រប់គ្រង LifeLink បានពិនិត្យរួច**)

បើកសារជូនដំណឹងដើម្បីមើលក្រុមឈាមដែលត្រូវការ ចំនួនឯកតា មន្ទីរពេទ្យ និងចម្ងាយ។

## ៥. យល់ព្រម ឬបដិសេធ

- **មុនពេលយល់ព្រម** កម្មវិធីសួរថា តើអ្នកមានករណីណាមួយដែរឬទេ ឧទាហរណ៍ មានទម្ងន់តិចជាង ៤៥ គីឡូក្រាម។ បើមាន មជ្ឈមណ្ឌលប្រហែលជាមិនអនុញ្ញាតឲ្យអ្នកបរិច្ចាគទេ។ សូមសួរមជ្ឈមណ្ឌលមុនពេលធ្វើដំណើរទៅ ឬចុច «បដិសេធ»។
- **យល់ព្រម**៖ អ្នកឃើញឈ្មោះ និងលេខទូរស័ព្ទរបស់គ្រួសារ។ ចុច **ចម្លងលេខទូរស័ព្ទ** ហើយទូរស័ព្ទទៅពួកគាត់។ លេខនេះមិនបានផ្ទៀងផ្ទាត់ទេ។ បើទាក់ទងមិនបាន សូមព្យាយាមម្តងទៀតក្រោយ។
- **បដិសេធ**៖ គ្មានអ្វីកើតឡើងទៀតទេ។ អ្នកផ្សេងនៅតែអាចជួយបាន។
- **គ្មានអ៊ីនធឺណិត?** ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងទូរស័ព្ទ ហើយនឹងផ្ញើនៅពេលមានអ៊ីនធឺណិត — អ្នកមិនចាំបាច់ឆ្លើយម្ដងទៀតទេ។

បើសំណើមើលទៅដូចជាក្លែងក្លាយ ឬមានគេសុំប្រាក់ ឬស្នើឲ្យប្រាក់អ្នក សូមចុច **រាយការណ៍ការស្នើសុំនេះ**។
មានតែអ្នកគ្រប់គ្រង LifeLink ទេដែលឃើញរបាយការណ៍របស់អ្នក។ ក្រុមគ្រួសារមិនដឹងថាអ្នកណាជាអ្នករាយការណ៍ទេ។

## ៦. ក្រោយពេលបរិច្ចាគ

ពេលមន្ទីរពេទ្យបញ្ជាក់ការបរិច្ចាគរបស់អ្នក អ្នកគ្រប់គ្រងនឹងកត់ត្រាវា។ ផ្ទាំង **ប្រវត្តិ** នឹងបង្ហាញ៖

- ការបរិច្ចាគទាំងអស់ដែលបានបញ្ជាក់
- **ជួយបានរហូតដល់ N អ្នកជំងឺ**៖ ឈាមមួយឯកតាត្រូវបានបំបែកជាកោសិកាឈាមក្រហម ប្លាស្មា និងប្លាកែត ដូច្នេះការបរិច្ចាគម្តងអាចជួយអ្នកជំងឺបានរហូតដល់បីនាក់
- ពេលដែលអ្នកអាចបរិច្ចាគម្តងទៀត

### មុនពេលទៅបរិច្ចាគ

- អ្នកត្រូវមានទម្ងន់យ៉ាងតិច ៤៥ គីឡូក្រាម ហើយជាធម្មតាមានអាយុពី ១៨ ដល់ ៦០ ឆ្នាំ។
- ញ៉ាំអាហារក្នុងរយៈពេល ៤ ម៉ោងមុនពេលបរិច្ចាគ ផឹកទឹកឲ្យបានច្រើន ហើយគេងឲ្យបានស្កប់ស្កល់នៅយប់មុន។
- យកអត្តសញ្ញាណប័ណ្ណទៅជាមួយ។
- ជាធម្មតា ឈាមដែលបរិច្ចាគម្តងនៅកម្ពុជាគឺ ៣៥០ មីលីលីត្រ។ ការបូមឈាមចំណាយពេលប្រហែល ១០ នាទី ហើយការមកបរិច្ចាគម្តងៗ ជាធម្មតាមិនដល់មួយម៉ោងទេ។

សូមរង់ចាំសិន កុំទាន់បរិច្ចាគ ប្រសិនបើអ្នក ឧទាហរណ៍ មានគ្រុនក្តៅ ឬបានលេបថ្នាំអង់ទីប៊ីយ៉ូទិកក្នុងរយៈពេល ២ សប្តាហ៍មុននេះ
កើតជំងឺគ្រុនឈាម ឬគ្រុនចាញ់ក្នុងរយៈពេល ៦ ខែមុននេះ ឬបានសាក់ ឬចោះលើខ្លួនក្នុងរយៈពេល ១២ ខែមុននេះ។
បញ្ជីពេញលេញមាននៅអេក្រង់ **អ្វីដែលត្រូវរំពឹងនៅពេលបរិច្ចាគឈាម** ក្នុងកម្មវិធី។

**កន្លែងបរិច្ចាគ៖** មជ្ឈមណ្ឌលជាតិផ្តល់ឈាម (NBTC) ផ្លូវលេខ ២៧១ ក្បែរមន្ទីរពេទ្យមិត្តភាពខ្មែរ-សូវៀត ភ្នំពេញ។
អាចមកបរិច្ចាគដោយផ្ទាល់ ដោយមិនចាំបាច់ណាត់ទុកមុន។ ផ្នែកផ្តល់ឈាមនៅមន្ទីរពេទ្យ និងយុទ្ធនាការបរិច្ចាគឈាមចល័ត ក៏ទទួលការបរិច្ចាគដែរ។

ការបរិច្ចាគឈាម គឺដោយស្ម័គ្រចិត្ត និងមិនទទួលប្រាក់តបស្នងឡើយ។ អាហារសម្រន់ និងអំណោយ គឺជាការអរគុណពីមជ្ឈមណ្ឌល។

## ៧. ផ្អាក ឬឈប់

- **ផ្អាកការជូនដំណឹង៖** នៅ **ខ្ញុំ → ប្រវត្តិរូបអ្នកបរិច្ចាគ** បិទ **អាចទទួលសំណើបាន**។ ប្រវត្តិរូបរបស់អ្នកនៅដដែល។
- **លុបគណនី៖** **ខ្ញុំ → លុបគណនី**។ ប្រវត្តិរូប ប្រភេទឈាម ទីតាំង និងលេខទូរស័ព្ទរបស់អ្នក នឹងត្រូវលុបចោល។ ចំនួនការបរិច្ចាគនៅតែមានក្នុងស្ថិតិរបស់ LifeLink ដោយគ្មានឈ្មោះ។ សកម្មភាពនេះមិនអាចត្រឡប់វិញបានទេ។
