# សំណួរញឹកញាប់

### តើនរណាទទួលបានការជូនដំណឹងអំពីការស្នើសុំ?

មានតែអ្នកបរិច្ចាគដែលមានក្រុមឈាមត្រូវគ្នានឹងអ្នកជំងឺ អាចទទួលសំណើបាន អាចបរិច្ចាគបាន និងនៅក្នុងចម្ងាយប្រហែល ១០ គីឡូម៉ែត្រពីមន្ទីរពេទ្យ
(ឬបានផ្តល់តែខណ្ឌ) ប៉ុណ្ណោះ។ គ្មាននរណាទទួលការជូនដំណឹងទេ រហូតដល់អ្នកគ្រប់គ្រងពិនិត្យសំណើរួច។

### តើខ្ញុំអាចបរិច្ចាគបានញឹកញាប់ប៉ុណ្ណា?

LifeLink រាប់ ៣ ខែ (៩០ ថ្ងៃ) សម្រាប់បុរស និង ៤ ខែ (១២០ ថ្ងៃ) សម្រាប់ស្ត្រី ដូចមជ្ឈមណ្ឌលផ្តល់ឈាមនៅកម្ពុជាអនុវត្ត។
បើអ្នកមិនប្រាប់ភេទ កម្មវិធីរាប់ ៤ ខែ។ បុគ្គលិកមជ្ឈមណ្ឌលជាអ្នកសម្រេចចុងក្រោយ។

### តើនរណាអាចមើលឃើញទីតាំងរបស់ខ្ញុំ?

អ្នកដទៃឃើញតែខណ្ឌរបស់អ្នក មិនឃើញទីតាំងជាក់លាក់ទេ។ ទីតាំងដែលអ្នកផ្តល់ ប្រើសម្រាប់តែវាស់ចម្ងាយទៅមន្ទីរពេទ្យប៉ុណ្ណោះ។

### តើនរណាអាចមើលឃើញលេខទូរស័ព្ទរបស់ខ្ញុំ?

លេខទូរស័ព្ទរបស់អ្នកស្នើសុំ បង្ហាញតែដល់អ្នកបរិច្ចាគដែល **យល់ព្រម** លើសំណើនោះប៉ុណ្ណោះ។ ព័ត៌មានអ្នកបរិច្ចាគ មានតែអ្នកគ្រប់គ្រង LifeLink ទេដែលឃើញ។
បញ្ជីសំណើលើគេហទំព័រ បង្ហាញអ្នកបរិច្ចាគដែលបានយល់ព្រម ដោយឈ្មោះដំបូង និងអក្សរកាត់ (ឧ. «Sothea N.») មិនដែលបង្ហាញលេខទូរស័ព្ទទេ។
ទំព័រនោះមិនបង្ហាញក្នុង Google Search ទេ ហើយការលុបគណនីនឹងលុបឈ្មោះរបស់អ្នកចេញពីវា។

### តើត្រូវចំណាយប្រាក់ទេ?

ទេ។ LifeLink មិនដែលសុំប្រាក់ពីអ្នកទេ។ តាមគោលនយោបាយជាតិ អ្នកជំងឺទទួលឈាមដោយឥតគិតថ្លៃ។ កុំទិញ ឬលក់ឈាមដាច់ខាត។

### ខ្ញុំមិនដឹងក្រុមឈាមរបស់ខ្ញុំទេ។

មន្ទីរពេទ្យអាចធ្វើតេស្តបាន។ បើគ្មានវា LifeLink មិនអាចផ្គូផ្គងអ្នកជាមួយអ្នកជំងឺបានទេ។

### តើខ្ញុំអាចឈប់ទទួលការជូនដំណឹង ដោយមិនលុបគណនីបានទេ?

បាន។ បិទ **អាចទទួលសំណើបាន** នៅ **ខ្ញុំ → ប្រវត្តិរូបអ្នកបរិច្ចាគ**។

### បើខ្ញុំគ្មានអ៊ីនធឺណិតពេលឆ្លើយ?

ចម្លើយរបស់អ្នកត្រូវបានរក្សាទុកក្នុងទូរស័ព្ទ ហើយនឹងផ្ញើនៅពេលមានអ៊ីនធឺណិត។

### មានគេសុំប្រាក់ពីខ្ញុំ ឬសំណើមើលទៅដូចជាក្លែងក្លាយ។

បើកសំណើនោះ ហើយចុច **រាយការណ៍ការស្នើសុំនេះ**។ មានតែអ្នកគ្រប់គ្រងទេដែលដឹងថាអ្នកណាជាអ្នករាយការណ៍។

### តើខ្ញុំលុបគណនីរបស់ខ្ញុំដោយរបៀបណា?

បើកផ្ទាំង «ខ្ញុំ» ហើយចុច «លុបគណនី»។ អ្នកនឹងត្រូវចូលគណនីម្តងទៀត ដើម្បីបញ្ជាក់ថាជាអ្នក។
បើគ្មានកម្មវិធី សូមធ្វើតាមជំហាននៅ [ទំព័រលុបគណនី](https://lifelinkkh.vercel.app/km/delete-account)។

### តើ LifeLink ជាផ្នែកមួយនៃមន្ទីរពេទ្យ ឬមជ្ឈមណ្ឌលជាតិផ្តល់ឈាមទេ?

ទេ។ LifeLink KH ជាគម្រោងសហគមន៍ open source ឯករាជ្យ។ វាជួយភ្ជាប់អ្នកបរិច្ចាគ និងអ្នកជំងឺ។
មន្ទីរពេទ្យ និងមជ្ឈមណ្ឌលជាតិផ្តល់ឈាម ជាអ្នកសម្រេចរាល់អ្វីៗទាក់ទងនឹងឈាម។

### មានកម្មវិធីសម្រាប់ iPhone ទេ?

កម្មវិធី iOS អាចដំណើរការបាន ប៉ុន្តែមិនទាន់មាននៅលើ App Store ទេ។ Android ជាប្រព័ន្ធដែលគាំទ្រ។
