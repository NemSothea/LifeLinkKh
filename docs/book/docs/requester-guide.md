សូមសួរផ្នែកផ្តល់ឈាមរបស់មន្ទីរពេទ្យ ថាត្រូវការអ្នកបរិច្ចាគពីក្រុមគ្រួសាររបស់អ្នកប៉ុន្មាននាក់ — ធ្វើវា **ព្រមជាមួយ** ការស្នើសុំក្នុង LifeLink។

## ១. ចូលគណនី

អ្នកណាដែលមានកម្មវិធី ក៏អាចស្នើសុំឈាមបានដែរ មិនចាំបាច់ចុះឈ្មោះជាអ្នកបរិច្ចាគទេ។
ដំឡើងពី [ទំព័រទាញយក](https://lifelinkkh.vercel.app/km/download) ហើយចូលគណនីជាមួយ Google ឬ Facebook។

## ២. ដាក់សំណើ

ចុច **ស្នើសុំឈាម** នៅផ្ទាំង **ដើម** (ក៏មាននៅផ្ទាំង **ខ្ញុំ** ដែរ)។ បំពេញ៖

| ព័ត៌មាន | ចំណាំ |
|---|---|
| **ក្រុមឈាមអ្នកជំងឺ** | តាមដែលមន្ទីរពេទ្យប្រាប់ |
| **ចំនួនឯកតា** | ចំនួនដែលមន្ទីរពេទ្យស្នើ |
| **មន្ទីរពេទ្យ** | ជ្រើសពីបញ្ជី |
| **ភាពបន្ទាន់** | បន្ទាន់បំផុត បន្ទាន់ ឬធម្មតា |
| **ត្រូវសួររកអ្នកណា?** | ឈ្មោះដែលអ្នកបរិច្ចាគត្រូវសួររកនៅមន្ទីរពេទ្យ |
| **លេខទូរស័ព្ទទាក់ទងវិញ** | លេខទូរស័ព្ទចល័តនៅកម្ពុជា ឧ. 012 345 678។ មានតែអ្នកបរិច្ចាគដែលយល់ព្រមទេដែលឃើញ។ |

មុនពេលបញ្ជូន កម្មវិធីរំលឹកថា វានឹងជូនដំណឹងទៅអ្នកបរិច្ចាគដែលអាចផ្តល់ឈាមឲ្យអ្នកជំងឺបាន រួមទាំងក្រុមឈាមផ្សេងទៀតដែល **ត្រូវគ្នា** មិនត្រឹមតែក្រុមដូចគ្នាទេ។

## ៣. ការពិនិត្យដោយអ្នកគ្រប់គ្រង

**មុននឹងជូនដំណឹងទៅអ្នកបរិច្ចាគ អ្នកគ្រប់គ្រងនឹងពិនិត្យថាការស្នើសុំនេះពិតប្រាកដ។** សំណើរបស់អ្នកបង្ហាញ
**កំពុងរង់ចាំការពិនិត្យ** — មិនទាន់មានអ្នកបរិច្ចាគណាម្នាក់ត្រូវបានទាក់ទងនៅឡើយទេ។

- **ត្រូវបានអនុម័ត៖** អ្នកទទួលសារជូនដំណឹង ហើយ LifeLink ជូនដំណឹងទៅអ្នកបរិច្ចាគដែលត្រូវគ្នានៅជិតមន្ទីរពេទ្យ។
- **មិនត្រូវបានអនុម័ត៖** អ្នកឃើញមូលហេតុពីអ្នកគ្រប់គ្រង។ ប្រសិនបើនៅតែត្រូវការឈាមមែន អ្នកអាចស្នើសុំម្តងទៀតដោយកែព័ត៌មានឱ្យបានត្រឹមត្រូវ។

## ៤. ពេលរង់ចាំអ្នកបរិច្ចាគ

បើកសំណើរបស់អ្នក ដើម្បីមើល៖

- ចំនួនអ្នកបរិច្ចាគដែលបានជូនដំណឹង និងចំនួនដែលបានយល់ព្រម
- **កំពុងរង់ចាំអ្នកបរិច្ចាគទីមួយឆ្លើយតប** រហូតដល់មាននរណាម្នាក់យល់ព្រម

អ្នកនឹងទទួលបានសារជូនដំណឹង៖ **«មានអ្នកបរិច្ចាគទទួលយកសំណើរបស់អ្នកហើយ។»** អ្នកបរិច្ចាគមានលេខទូរស័ព្ទរបស់អ្នក ហើយនឹងទូរស័ព្ទមក ឬទៅមន្ទីរពេទ្យ។

**មិនទាន់មានអ្នកបរិច្ចាគត្រូវគ្នានៅជិតនេះទេ?** សាច់ញាតិ និងមិត្តភក្តិរបស់អ្នកនៅតែអាចជួយបាន។ នៅផ្នែកផ្តល់ឈាមរបស់មន្ទីរពេទ្យ
អ្នកបរិច្ចាគមានក្រុមឈាមអ្វីក៏បាន អាចបរិច្ចាគជំនួសឲ្យអ្នកជំងឺរបស់អ្នក។

## ៥. បិទសំណើ

- ពេលមានឈាមគ្រប់គ្រាន់ អ្នកគ្រប់គ្រងនឹងសម្គាល់សំណើថា «បានបំពេញ» បន្ទាប់ពីបញ្ជាក់ការបរិច្ចាគ។
- បើលែងត្រូវការឈាម ចុច **បោះបង់ការស្នើសុំ**។ អ្នកបរិច្ចាគដែលបានជូនដំណឹងរួច នឹងមិនអាចយល់ព្រមបានទៀត។

## សុវត្ថិភាព

- **ឈាមឥតគិតថ្លៃ។** តាមគោលនយោបាយជាតិ អ្នកជំងឺទទួលឈាមដោយឥតគិតថ្លៃ។ មន្ទីរពេទ្យអាចគិតថ្លៃសេវាពិនិត្យ និងរៀបចំឈាម។ សូមសួរមន្ទីរពេទ្យថាត្រូវបង់ប៉ុន្មាន។
- **កុំបង់ប្រាក់ឲ្យនរណាម្នាក់ ដើម្បីទិញឈាម ឬជួលអ្នកបរិច្ចាគ។** បើមានគេមកលក់ឈាមឲ្យអ្នក សូមប្រាប់មន្ទីរពេទ្យ។ LifeLink មិនដែលសុំប្រាក់ពីអ្នកទេ។
- **សាច់ញាតិបង្កើត៖** កុំរៀបចំបញ្ចូលឈាមរបស់ឪពុកម្តាយ កូន ឬបងប្អូនបង្កើត ទៅអ្នកជំងឺដោយផ្ទាល់។ សូមឲ្យពួកគាត់បរិច្ចាគទៅផ្នែកផ្តល់ឈាម។ មន្ទីរពេទ្យជាអ្នកសម្រេចពីរបៀបប្រើឈាមពីសាច់ញាតិ។
