# LifeLink KH ជាអ្វី

:::note ពិនិត្យភាសា `[km-review]`
ទំព័រនេះត្រូវការឲ្យអ្នកនិយាយភាសាខ្មែរពិនិត្យ។ បើឃើញពាក្យមិនធម្មជាតិ សូមចុច «Edit this page» ខាងក្រោម ឬបើក [issue ការបកប្រែ](https://github.com/NemSothea/LifeLinkKh/issues/new?template=translation.yml)។
:::

**ជីវិត — LifeLink KH** ជាកម្មវិធីឥតគិតថ្លៃ ដែលភ្ជាប់អ្នកជំងឺ និងក្រុមគ្រួសារដែលត្រូវការឈាម
ជាមួយអ្នកបរិច្ចាគស្ម័គ្រចិត្តនៅក្បែរ ដែលមានក្រុមឈាមត្រូវគ្នា។

នៅកម្ពុជា ពេលត្រូវការឈាមបន្ទាន់ មនុស្សភាគច្រើននៅតែបង្ហោះលើហ្វេសប៊ុក។ ការបង្ហោះនោះទៅដល់តែអ្នកដែលកំពុងមើលចំពេល
មិនអាចជ្រើសតាមក្រុមឈាម ឬចម្ងាយ ហើយមិនអាចដាស់ទូរស័ព្ទនៅម៉ោង ២ យប់បានទេ។ LifeLink ផ្ញើសារជូនដំណឹងភ្លាមៗ
ទៅតែអ្នកបរិច្ចាគដែលមានក្រុមឈាមត្រូវគ្នា និងនៅជិតមន្ទីរពេទ្យប៉ុណ្ណោះ។

:::info មិនជំនួសមជ្ឈមណ្ឌលផ្តល់ឈាមទេ
LifeLink KH ជួយភ្ជាប់អ្នកបរិច្ចាគឈាម និងអ្នកជំងឺ។ វាមិនជំនួសមជ្ឈមណ្ឌលជាតិផ្តល់ឈាម ឬដំបូន្មានវេជ្ជសាស្ត្រឡើយ។
ពេលមានអាសន្ន សូមពិភាក្សាជាមួយមន្ទីរពេទ្យជាមុនសិន។
:::

## ដំណើរការក្នុង ៤ ជំហាន

1. **គ្រួសារស្នើសុំឈាម** ក្នុងកម្មវិធី៖ ក្រុមឈាមអ្នកជំងឺ ចំនួនឯកតា មន្ទីរពេទ្យ ភាពបន្ទាន់ និងលេខទូរស័ព្ទទាក់ទងវិញ។
2. **អ្នកគ្រប់គ្រងពិនិត្យថាការស្នើសុំនេះពិតប្រាកដ** មុននឹងជូនដំណឹងទៅនរណាម្នាក់។
3. **LifeLink ជូនដំណឹងទៅអ្នកបរិច្ចាគដែលត្រូវគ្នា**៖ មានក្រុមឈាមត្រូវគ្នា អាចទទួលសំណើបាន អាចបរិច្ចាគបាន និងនៅក្នុងចម្ងាយប្រហែល ១០ គីឡូម៉ែត្រពីមន្ទីរពេទ្យ។
4. **អ្នកបរិច្ចាគយល់ព្រម** ឃើញលេខទូរស័ព្ទគ្រួសារ ហើយទៅបរិច្ចាគនៅមន្ទីរពេទ្យ ឬផ្នែកផ្តល់ឈាម។ គ្រួសារទទួលដំណឹងថាមានអ្នកបរិច្ចាគកំពុងមក។

## អ្វីដែលគួរដឹងជាមុន

- **ឥតគិតថ្លៃ។** LifeLink មិនដែលសុំប្រាក់ពីអ្នកទេ។ តាមគោលនយោបាយជាតិ អ្នកជំងឺទទួលឈាមដោយឥតគិតថ្លៃ។ កុំបង់ប្រាក់ឲ្យនរណាម្នាក់ដើម្បីទិញឈាម ឬជួលអ្នកបរិច្ចាគ។
- **សាច់ញាតិណាក៏អាចជួយបាន។** នៅផ្នែកផ្តល់ឈាមរបស់មន្ទីរពេទ្យ សាច់ញាតិមានក្រុមឈាម *អ្វីក៏បាន* អាចបរិច្ចាគ ហើយផ្នែកផ្តល់ឈាមនឹងផ្តល់ឈាមក្រុមដែលអ្នកជំងឺត្រូវការ។ មើល [របៀបរកឈាមសម្រាប់អ្នកជំងឺ](https://lifelinkkh.vercel.app/km/getting-blood)។
- **ទីតាំងជាក់លាក់របស់អ្នកជាការសម្ងាត់។** អ្នកដទៃឃើញតែខណ្ឌរបស់អ្នកប៉ុណ្ណោះ។
