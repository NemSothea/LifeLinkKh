# ដំឡើងកម្មវិធី (Android)

:::note ពិនិត្យភាសា `[km-review]`
ទំព័រនេះត្រូវការឲ្យអ្នកនិយាយភាសាខ្មែរពិនិត្យ។ បើឃើញពាក្យមិនធម្មជាតិ សូមចុច «Edit this page» ខាងក្រោម ឬបើក [issue ការបកប្រែ](https://github.com/NemSothea/LifeLinkKh/issues/new?template=translation.yml)។
:::

LifeLink KH ឥតគិតថ្លៃ ហើយ **មិនទាន់មាននៅលើ Play Store នៅឡើយទេ**។ អ្នកទាញយកឯកសារ APK ពីគេហទំព័រ ហើយដំឡើងដោយខ្លួនឯង។ ចំណាយពេលប្រហែលមួយនាទី។

**ត្រូវការ៖** ទូរស័ព្ទ Android កំណែ 7.0 ឡើងទៅ។

## ១. ទាញយក

នៅលើទូរស័ព្ទ សូមបើក [lifelinkkh.vercel.app/km/download](https://lifelinkkh.vercel.app/km/download) ហើយចុច **ទាញយកសម្រាប់ Android (APK)**។

កំពុងប្រើកុំព្យូទ័រមែនទេ? ទំព័រទាញយកមានកូដ QR។ សូមស្កេនវាដោយកាមេរ៉ាទូរស័ព្ទ ដើម្បីបើកទំព័រនោះនៅលើទូរស័ព្ទ។

:::warning ទាញយកតែពីគេហទំព័រ LifeLink ប៉ុណ្ណោះ
កុំដំឡើងឯកសារ APK របស់ LifeLink ដែលនរណាម្នាក់ផ្ញើឲ្យអ្នកតាម Telegram ឬ Facebook។ វាប្រហែលជាមិនមែនជារបស់យើងទេ។
:::

## ២. អនុញ្ញាតឲ្យដំឡើង

បើកឯកសារដែលបានទាញយក។ បើ Android និយាយថាមិនអនុញ្ញាតឲ្យដំឡើងពីប្រភពនេះ សូមចុច **ការកំណត់** បើក **អនុញ្ញាតពីប្រភពនេះ** សម្រាប់កម្មវិធីរុករករបស់អ្នក រួចត្រឡប់ក្រោយ។

## ៣. ដំឡើង

ចុច **ដំឡើង**។ Android ឬ Google Play Protect អាចនិយាយថា **«កម្មវិធីនេះប្រហែលជាមិនមានសុវត្ថិភាព»**។ វានិយាយបែបនេះចំពោះរាល់កម្មវិធីដែលមិនមកពី Play Store
មិនមែនមានន័យថារកឃើញអ្វីនៅក្នុង LifeLink ទេ។ សូមជ្រើស **នៅតែដំឡើង**។

## ៤. បើក និងចូលគណនី

បើក LifeLink ហើយចូលគណនីជាមួយ Google (ឬ Facebook នៅក្នុង **វិធីផ្សេងទៀតដើម្បីចូល**)។ បន្ទាប់មក សូមអាន [មគ្គុទ្ទេសក៍អ្នកបរិច្ចាគ](./donor-guide.md) ឬ [មគ្គុទ្ទេសក៍ស្នើសុំឈាម](./requester-guide.md)។

## ការធ្វើបច្ចុប្បន្នភាព

កម្មវិធីនឹងប្រាប់អ្នកពេលមានកំណែថ្មី។ សូមត្រឡប់ទៅទំព័រទាញយក ទាញយកម្តងទៀត ហើយដំឡើង **ពីលើ** កំណែចាស់។ អ្នកនៅតែចូលគណនីដដែល ហើយប្រវត្តិរបស់អ្នកនៅដដែល។ មិនចាំបាច់លុបកម្មវិធីចាស់ជាមុនទេ។

## ពិនិត្យឯកសារ (មិនបង្ខំ)

រាល់កំណែនៅលើ [GitHub Releases](https://github.com/NemSothea/LifeLinkKh/releases/latest) មានឯកសារពីរ៖ `lifelink-kh.apk` និង `lifelink-kh.apk.sha256` ដែលជាស្នាមម្រាមដៃរបស់វា។
នៅលើកុំព្យូទ័រ ដាក់ឯកសារទាំងពីរក្នុងថតតែមួយ ហើយដំណើរការ៖

```bash
shasum -a 256 -c lifelink-kh.apk.sha256      # macOS / Linux: បង្ហាញ "lifelink-kh.apk: OK"
```

កំណត់ចំណាំកំណែថ្មីក៏បង្ហាញស្នាមម្រាមដៃ **វិញ្ញាបនបត្រចុះហត្ថលេខា** ដែរ។ វាដូចគ្នាគ្រប់កំណែ។ បើវាផ្លាស់ប្តូរ សូមកុំដំឡើង ហើយប្រាប់យើង។
