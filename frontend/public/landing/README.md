# Landing page resources

- `app-home-en.png` and `app-home-km.png`: unchanged real Android screenshots copied from `docs/assets/screens/`. These are illustrative app previews, not live request data.
- `donor.svg` and `family.svg`: reusable, code-authored red and blush illustrations matching the supplied landing concept. Interface icons use the existing Lucide package; the brand mark remains the existing app mark.
- `angkor-wat.png`: transparent decorative artwork generated with the built-in imagegen tool, then copied into this project. No external API/CLI was used.

## Exact imagegen prompt

Use case: illustration-story
Asset type: decorative landing-page provenance illustration, transparent PNG
Primary request: A refined, minimal front-on illustration of Cambodia's Angkor Wat, like the small pale-red temple drawing in the supplied landing-page concept. Five recognisable lotus-shaped towers, long low galleries, a few simple round trees flanking the temple, small pale blush sun. Wide horizontal composition, entire temple visible, generous transparent margin. Style: delicate monochrome line art with restrained flat blush accents, clean architectural silhouette, warm community website, no gradients or texture. Palette: muted red #C62828 linework and pale blush #FCE9E7 fills. No lettering, no logos, no people, no medical symbols, no hospital endorsement, no border. Genuinely transparent background. Designed to be readable at 240px wide.
